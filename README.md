## 🧠 Sobre o projeto

O **LiteMix** é uma ferramenta Web3 inspirada no Remix IDE, criada para simplificar o processo de desenvolvimento e deploy de smart contracts.

A proposta é oferecer uma experiência mais leve e direta, permitindo que desenvolvedores compilem e implantem contratos em poucos cliques, sem a complexidade de ferramentas tradicionais.

---

## ⚙️ Funcionalidades

* ✍️ Editor de código Solidity no navegador
* ⚡ Compilação instantânea (solc-js)
* 🔗 Integração com MetaMask
* 🚀 Deploy em testnets (Sepolia)
* 📦 Exibição de ABI e Bytecode
* 📜 Logs de compilação e deploy
* 🌐 Link direto para explorer (Etherscan)

---

## 🧩 Tecnologias utilizadas

* React / Next.js
* Ethers.js
* Solidity (solc-js)
* Monaco Editor
* Tailwind CSS
* MetaMask (Injected Provider)

---

## 🔐 Como funciona

1. O usuário escreve ou cola um contrato Solidity
2. O código é compilado diretamente no browser
3. A carteira é conectada via MetaMask
4. O contrato é implantado na blockchain (Sepolia)
5. O endereço e a transação são retornados

---

## 🧪 Rede utilizada

* Ethereum Testnet (Sepolia)
